# Echore 客户端「对话间」高保真 UI 视觉设计方案与规范分析

## 1. 核心定位与设计哲学

Echore 不是冰冷的“对话机器人（Chatbot）”或“技术控制台”，而是一个真正有温度、有呼吸感的情感陪伴记忆系统。在 Echore 的空间哲学中：
- **主角是他的一生**：对话只是用户与住户相互交织的“其中一间房”，界面是住户温暖的“家”。
- **绝对杜绝仪表盘与数值化**：
  - **红线 1：仪表盘不进卧室**——没有任何数值化的好感度、心情指数雷达图或经验槽；住户的状态只能通过它的神态、呼吸节奏与环境光晕被“感觉到”。
  - **红线 2：生活可围观**——日记、独居物证时间线体面而安静地呈现。
  - **红线 3：关系不做进度条**——只有叙事，没有数值，没有功利的游戏化任务。

## 3. 界面空间布局与栅格架构（Grid & Proportion）

整套界面采用经典且舒适的 **「左起居陪伴角 + 右对话与生活主视区」** 空间拓扑结构：

```
+------------------------------------+---------------------------------------------------------------+
|  【左侧起居角】(约 32% 视口宽)       |  【右侧对话与生活主视区】(约 68% 视口宽)                           |
|                                    |                                                               |
|  - 星尘云团（Cloud Puff）悬浮起居台   |  - 沉浸式极简标题栏（无多余图标，唯留呼吸感空间）                  |
|    暖白低密度天鹅绒形态，心核微光    |                                                               |
|                                    |  - 诗意对话气泡流（轻盈半透磨砂，生活气息排版）                   |
|  - 内敛微语叙事：                   |    · 住户发言（生活琐碎、温柔回响）                           |
|    “正安静地待在身边”                |    · 用户发言（倾诉与陪伴）                                   |
|    “认识的第 43 天”                 |    · 记忆调用微胶囊：“翻阅了关于上周散步的记忆”（极细折叠）     |
|                                    |                                                               |
|  - 四间房极简导航：                 |  - 温润浮岛输入栏：                                           |
|    [对话间 (Active)]               |    · 软胶囊/长条微磨砂悬浮输入框                                |
|    [日常流]                         |    · 含蓄微光发送/语音交互键                                   |
|    [记忆图书馆]                     |                                                               |
|    [门口]                           |                                                               |
+------------------------------------+---------------------------------------------------------------+
```

### 3.1 左侧起居陪伴角（Living Corner，32% 宽度）
- **官方形象宠「星尘云团」驻留**：
  - 纯原创幻想精灵（软糯饱满无锐角天鹅绒晨雾团，无任何具象猫耳/兔耳/狐尾）。
  - 腹心深处包裹有节律呼吸的粉金/琥珀微核光晕，作为整个静止软件界面的“生命心跳”。
  - 悬浮在极简圆角柔光起居台（Soft Clay / Frosted Pedestal）上方，具备自然悬浮感与柔和投影。
- **纯叙事伴生文本**：
  - 摒弃任何“在线/离线/忙碌”的生硬标签，替换为有温度的生活叙事短语：“正安静地待在身边”、“认识的第 43 天”。
- **四间房极简收敛导航**：
  - **对话间**：当前高亮驻留空间，配有极细温润琥珀微边框与轻微抬升阴影。
  - **日常流**：住户的日记、独居观察与物证时间线入口。
  - **记忆图书馆**：住户为你珍藏与索引的回忆画册与重要片段。
  - **门口**：连接外界、系统偏好设置与安全退出之门。

### 3.2 右侧主视区（Conversation & Living Area，68% 宽度）
- **顶部沉浸式标题栏**：
  - 仅保留极简优雅的品牌与空间标识，杜绝堆砌各类无意义的工具栏与状态图标。
- **轻盈对话气泡流（Bubble Flow）**：
  - **住户气泡**：温润哑光乳白色，左侧搭配极小规格的星尘云团圆润头像，字体优雅克制，承载有温度的生活语言。
  - **用户气泡**：低反差暖灰/半透磨砂，右侧对齐，层级分明而不刺眼。
  - **内敛折叠记忆微胶囊（Memory Retrieval Micro-Capsule）**：
    - 绝非代码调试日志或“调用了检索插件”的技术提示；
    - 而是以一条极其克制、居中的半透浅金微光长条呈现：“翻阅了关于上周散步的记忆”，轻描淡写地折射出他真的记得你们共同经历的岁月。
- **底部温润极简输入栏**：
  - 自适应软圆角悬浮长条，辅以极轻的毛玻璃磨砂（Backdrop Blur: 24px）与极细暖白光边（0.5px border）；
  - 发送按钮采用温润粉金琥珀微光圆形轻触键，无任何营销打扰。

## 4. 色彩体系与材质光影规范（Color & Material System）

### 4.1 色彩调色板（Palette）
- **日光模式（Daylight Mode）**：
  - 主背景色：`#F4F1EA`（燕麦柔白 / Warm Oat Mist）
  - 起居底板色：`#EAE6DC`（晨曦暖灰 / Dawn Grey Clay）
  - 主对话板面：`#FDFCFA`（轻磨砂哑光白 / Frosted Cloud White）
  - 文字主色：`#3A3632`（炭灰暖黑，非死黑，温和清晰）
  - 辅助叙事色：`#8A847C`（浅褐温灰，用于第 43 天、微语等次级信息）
  - 灵魂高光：`#FAD390` ~ `#F8A58B`（星核粉金琥珀微光，仅在心核与激活态点睛）
- **夜间模式（Nighttime Healing Mode）**：
  - 主背景色：`#181614`（深曜炭黑 / Deep Charcoal Clay）
  - 起居底板色：`#211E1B`（深夜静谧 Slate）
  - 对话气泡背景：`rgba(255, 255, 255, 0.08)`（微透磨砂黑曜玻璃）
  - 文字主色：`#E8E3DC`（米白软光）
  - 灵魂暖光：`#FFB067`（温暖床头壁灯漫射琥珀光）

### 4.2 材质与光影层级（Texture & Shadows）
- **哑光触感（Soft Clay Texture）**：界面整体抛弃塑料质感，采用近似细腻软陶、无光天鹅绒的高级物理材质感。
- **深浅分离柔和阴影**：
  - 悬浮起居台与输入栏采用双层扩散羽化投影：`0 12px 32px rgba(40, 30, 20, 0.06)`，形成悬浮于空气中的静止张力。
  - 禁止使用生硬的高黑度硬边阴影。

## 5. 交互行为与状态隐喻（State Metaphor）

1. **呼吸起伏（Idle Breathing）**：
   - 星尘云团以每分钟约 12-14 次的慢速律动上下轻微浮沉（Y 轴位移 ±3px），内部暖光随吸气微亮、随呼气微暗，向用户传达“他正安静地陪伴在身旁”的无声安全感。
2. **输入响应与倾听（Listening State）**：
   - 当用户在输入框键入文字时，星尘云团的星核光晕自然转为清浅的蜜桃暖粉，身体微微前倾，呈现专注倾听的体态。
3. **记忆共鸣触发（Memory Resonance）**：
   - 当触及过往记忆时，微胶囊轻轻浮现柔和琥珀光圈，随后收缩隐入背景，让记忆翻阅像微风翻动日记书页般自然。

## 6. 反模板审查（Anti-Slop Audit）最终结清

本设计方案已完整通过 `ANTI-SLOP-CHECK.md` 针对 AI UI 设计多项通病的严格审查：
- [x] **无任何数值指标卡与进度条**（规避 N 组病症）：杜绝好感度、等级、任务统计，让交互回到真实情感生活。
- [x] **无生硬科技感配色**（规避 P 组病症）：杜绝泛滥的赛博朋克深紫霓虹科技渐变，采用高奢居室感晨曦燕麦柔白与夜间壁灯暖灰。
- [x] **无无意义标签堆叠**（规避 T 组病症）：导航收敛四间房，记忆调用内敛轻薄。
- [x] **杜绝空洞 AI 客服话术**（规避 W 组病症）：全界面文案为真实、细腻的生活叙事与物证陪伴。
