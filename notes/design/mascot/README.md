# Echore 官方品牌形象宠：星尘云团（Cloud Puff）常态概念设计

## 1. 核心形象定位
- **命名**：星尘云团（Cloud Puff）
- **物种定位**：纯原创治愈系幻想生物（低密度天鹅绒晨雾/云絮精灵）。
- **设计哲学**：
  - **纯粹非动物化**：彻底杜绝猫耳、兔耳、狐狸尾、硬爪等具象动物器官，以纯粹无锐角的软糯云团为形态基底。
  - **触感感知**：表层呈现哑光细腻的天鹅绒雾气触感，柔化环境边界。
  - **情绪发生源（星核 Star-Core）**：云团腹心深处包裹温润内敛的暖金/琥珀微光微核，隐喻产品 Echore 倾听、守护与回响心声的温柔共鸣。
  - **婴儿图式五官**：极简深灰豆豆眼，眼距适度拉开，无嘴巴无鼻子，零攻击性与杜绝恐怖谷。
  - **构图规范**：1:1 正方形画幅，主体绝对居中，留足 20% 以上安全边距，平滑素雅摄影棚浅灰底，便于后期抠图与全渠道资产提取。

## 3. 使用建议与提取指南
- **扣像提取**：4款图片均置于高宽容度的浅灰白工作室地面上，推荐使用蒙版或色键工具一键提取，云团边缘的半透明绒毛已自带抗锯齿过渡。
- **UI 与品牌应用**：
  - `cloud_puff_pure_velvet.png` 推荐作为 App 启动页、空状态占位、常驻助手形象；
  - `cloud_puff_heart_glow.png` 推荐用于“心愿达成”、“共鸣记录”、“成就解锁”等暖心互动节点；
  - `cloud_puff_stardust_rim.png` 推荐用于品牌官方头图、夜间模式、会员权益或营销 KV 首屏。
