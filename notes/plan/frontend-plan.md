> 状态：**阶段性冻结归档**。  
> 核心决议（2026-11-11）：
> **UI 细节是无底洞。过早深陷入精灵材质、全画布物理游荡与像素动画会极大拖慢核心生命系统的演进。现阶段全面冻结高保真复杂 UI 与动效开发，将已有探索产物（`notes/design/{demos,mascot,ui}/`）封存归档；主线重心立即切换回「核心内部算法与各人设原型反应测试」。**

## 0. 架构决策与设计红线

### 0.1 核心技术选型
- **架构形态**：原生 Web / PWA（Progressive Web App），桌面优先，随时可安装至 Dock/任务栏常驻。
- **技术栈**：**零构建原生 HTML5 + ES Module JS + 原生 CSS**。
  - **零编译负担**：无 Webpack/Vite/Rollup 打包，无 TS 运行时编译，直接由 Bun (Hono) 静态托管服务。
  - **极致稳定**：彻底杜绝 React/Vue 生态常见的热更新失效、页面无故重刷导致对话状态丢失的痼疾。
  - **轻量常驻**：内存占用低，后台常驻不发热。
- **通信层**：
  - **REST (Fetch)**：常规指令、会话初始化、历史拉取、配置读写。
  - **WebSocket / SSE**：实时心跳事件流（心境交接单 `expression` 推送、独居物证落库通知、主动破冰与流式回复）。

### 0.2 三条不可逾越的设计红线
1. **仪表盘不进卧室**：激素数值、好感度、关系进度条一律不许出现。状态只能被「感觉到」（体态、微核光温、语气、氛围），不能被「读数」。
2. **生活可围观**：独居生活、日记、记忆体量都是正式内容形态，在「日常流」与「记忆图书馆」有体面的去处，不许只剩聊天流。
3. **关系不做进度条**：关系状态由事件日志派生、只以叙事形式呈现（「你们认识的第 43 天」「上次吵架还没说开」），禁止经验值化。

## 1. 形象系统：官方宠落地与生成后置

### 1.1 资产落地（已完成）
- **官方住户形态**：纯原创幻想精灵「星尘云团（Cloud Puff）」，基准款式为纯白极简天鹅绒款（Pure Velvet）。
- **7 状态资产包 (`notes/design/mascot/default_pack/`)**：
  - `normal.png`（常态）：平静温润天鹅绒云团，腹心慢心率暖光微核。
  - `happy.png`（开心）：轻弹膨胀，蜜桃粉金暖光，星尘微粒跳跃，豆豆眼弯月。
  - `aggrieved.png`（委屈）：扁塌下沉贴地，清冷冰青微光，眼神微垂。
  - `alienated.png`（疏离）：边缘凝实，冷白微光，周身星屑熄灭，克制距离感。
  - `sleepy.png`（困倦）：趴伏小枕头，琥珀微光，闭目起伏呼吸。
  - `yearning.png`（想念）：云体前倾依恋，极光紫粉晕，眼神专注。
  - `solitary.png`（独居）：蜷缩独处，伴随一本微光小书，日常流专用。
- **规范配置文件**：`manifest.json` 规范定义了每个状态对应的引擎心境 `expression` 枚举。

### 1.2 前端实现机制
- **查表切换**：前端维护单例 `MascotPresenter`，根据后端每轮交接单的 `expression` 字段平滑淡入淡出切换，前端不做情绪推断。
- **纯 CSS 生命感**：
  - 基于 CSS `@keyframes` 赋予呼吸起伏（慢速 4s-6s 律动）。
  - 基于 `filter: drop-shadow()` 配合光核颜色做微弱的外发光呼吸散射。
  - 零 Canvas、零 3D/骨骼，超轻量，不吃 GPU。

### 1.3 策略调整说明
- 原初稿 §6 规划的「Muse 式 AI 多图衍生、模板滑块调节、同源 CI 机检」**全部后置至 V2 / F-Extra**。
- F 系列里程碑专注保障官方云团住户的表现力与四间房的完整性。

## 2. 信息架构：四间房骨架

```
┌────────────────────────────────────────────────────────┐
│                        Echore                          │
├─────────┬──────────────────────────────────────────────┤
│ 导航栏   │ 主视区 (单页路由/Tab切换)                      │
│         │                                              │
│ [对话间] │ ┌──────────────────┐  ┌───────────────────┐ │
│ [日常流] │ │ 星尘云团常态区   │  │ 对话消息流        │ │
│ [图书馆] │ │ (呼吸/微光/7态)  │  │ (气泡/打字机/折叠)│ │
│ [门口]   │ └──────────────────┘  └───────────────────┘ │
│         │ ──────────────────────────────────────────── │
│ [伴生]   │ 底部输入框 / 状态栏                          │
└─────────┴──────────────────────────────────────────────┘
```

1. **对话间 (Living Room)**：
   - 居中或左侧常驻星尘云团（随基调切换 7 态），右侧为平滑滚动的对话流。
   - 工具调用过程（搜索、查记忆）默认折叠为收敛的小药丸，不露调试细节。
   - 主动破冰消息无特殊徽章（不破坏沉浸感）。
2. **日常流 (Daily Stream)**：
   - 按天倒序呈现独居引擎产出的物证卡片（S1 读书批注、S2 游标推进、出门见闻）。
   - 伴随星尘云团的 `solitary` 独居状态。
   - 暗中准备（S3）只在被递出时才回溯留痕。
3. **记忆图书馆 (Library)**：
   - 体量计数牌（认识天数、记忆条数、断言数——像代码仓统计一样安静，不做徽章）。
   - 日记本（Journal 按日翻阅，只读）。
   - 牵挂（书架上几本「没合上的书」）。
4. **门口 (Threshold)**：
   - Genesis 领养面试与人设选择。
   - 信箱（流浪信、重要告知信封态）。
   - 宪法护栏设置与数据导出打包。

## 3. 分阶段实施里程碑（F1–F3）

### 【F1：能住 · 对话与灵动陪伴】
*目标：建立原生 PWA 骨架，接通 Hono 后端，星尘云团表情随对话基调平滑切换，实现真聊一天。*
- [ ] **F1.1 前端工程与静态服务**：
  - 在后端 Bun (Hono) 中集成静态文件服务（托管 `web/` 目录）。
  - 创建纯原生基础入口：`index.html`、`app.js`、`styles.css`，配置 `manifest.webmanifest`（支持安装为桌面 PWA）。
- [ ] **F1.2 星尘云团展示组件 (`MascotComponent`)**：
  - 加载 `default_pack/` 资产与 `manifest.json`。
  - 实现透明图层双缓冲 cross-fade 平滑切换。
  - 实现纯 CSS 的柔和呼吸微动与外发光光晕效果。
- [ ] **F1.3 对话间基础界面**：
  - 聊天气泡布局（时间线、用户输入框、自适应高度多行文本）。
  - 流式打字机效果（对接 SSE / 流式响应）。
  - 工具调用折叠胶囊（“翻阅了关于上次旅行的记忆...”）。
- [ ] **F1.4 引擎状态与心境联动**：
  - 对接心境交接单的 `expression` 字段，实现实时换脸。
  - 测试 7 种状态在对话中的真实表现。

### 【F2：有生活 · 独居物证与记忆图书馆】
*目标：打破单一聊天流，呈现 AI 独立存在的证据与长期记忆积淀。*
- [ ] **F2.1 日常流界面 (Daily Stream)**：
  - 独居物证时间线组件（按天倒序分组）。
  - 物证卡片渲染（书籍笔记、代码探索、思绪碎念）。
  - S3 暗中准备揭晓事件的留痕卡片渲染。
- [ ] **F2.2 记忆图书馆 (Memory Library)**：
  - 体量计数概览面板（纯粹数据统计展示）。
  - 日记本视图（按日期日历/翻页式查看前台生成的 Journal）。
  - 牵挂书架（未解决事项以“翻开的书”呈现，已解决则合上）。
- [ ] **F2.3 房间切换路由**：
  - 零依赖的前端 Hash 路由或状态切换，保证四间房无缝切换不重载。

### 【F3：有温度与主权 · Genesis 门口与信箱】
*目标：完整闭环生命周期（诞生、授权、流浪信、数据导出）。*
- [ ] **F3.1 Genesis 领养面试流程**：
  - 引导式入驻流程（起名、个性倾向选择、开机第一句话）。
  - 权限逐项透明签字（主动打扰频次、桌面感知开关）。
- [ ] **F3.2 流浪与离线信箱**：
  - 独立信封态卡片，支持慢速阅读与存档。
- [ ] **F3.3 设置与数据主权**：
  - 护栏配置（免打扰时间段、静默窗）。
  - 一键导出全部记忆仓 Zip 包（可迁移性保障）。
